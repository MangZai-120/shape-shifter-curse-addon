# 独立新法术系统

本份资料位于完整SSCA试验副本的`neomagic`分支中。后续新体系开发在`SSCA新法术系统试验田`进行，见[试验田说明](../新法术试验田说明.md)；原项目及其`main`分开维护。

本目录专门存放崩解度新法术系统的设计、后续源码、数据、资源及验证材料。新体系与现有法术体系隔离；本轮仅整理目录和设计，不接入运行时。

## 文档入口

- [完整系统设计V2](docs/SSCA新法术系统完整设计V2.md)：包含术式语法、研究循环、身体承载与成长的整套设计。
- [新UI设计说明](docs/UI设计说明V2.md)及[可操作界面原型](ui/研究界面原型.html)：用于评审流程、布局和规则演算。
- [新法术系统设计方案](docs/SSCA新法术系统设计方案.md)：以后续补充确认的规则为准。
- [原始讨论记录](docs/SSCA崩解度法术系统设计方案.md)：保留历史讨论及否决标注，其中的旧接入建议不作为当前实施要求。

## 隔离边界

| 内容 | 要求 |
| --- | --- |
| 现有法术体系 | 保留当前法力、法术书、卷轴、法阵、熟练度、按键和施法流程 |
| 新体系的施法入口 | 单独定义，不能自动劫持现有法术书或单独卷轴 |
| 法术定义与注册 | 独立目录、数据标识和注册入口，不覆盖旧法术定义 |
| 玩家状态 | 崩解度、恢复等待、熟练度和累计异常独立保存与同步 |
| 施法会话与冷却 | 新体系独立管理；新法术内部共享冷却不直接写入旧法术共享表 |
| 配置与数据 | 独立命名，不复用旧mana字段存储崩解度，不自动迁移旧奖励与存档 |
| HUD与网络 | 独立状态、消息标识和显示入口，不能隐藏或改写旧法术资源 |
| 原生形态技能 | 保持现有资源与行为；新体系可以读取当前形态来获得S及FormRoll |
| 算法参考 | 可以参考旧体系的渐进结算节奏，但不复用其有状态的施法会话或资源实例 |
| 后续互通 | 如需转换旧卷轴、继承旧Perk或共用按键，另行设计明确适配 |

未来新增文件继续收在本目录内。需要开发源码、数据或测试时，再分别增加对应子目录；当前不创建空实现，也不把本目录纳入主项目的生产source set。

主项目目前默认编译、打包的内容仍来自原有`src/main`，本目录不是已经启用的新法术模块。具体独立模块构建方式、入口物品与命名空间待实现阶段确定。
