# SSCA 新法术系统完整设计 V2

日期：2026-10-27。适用：独立试验田、`neomagic`分支。

交付状态：当前系统范围已接入试验田Minecraft实现，代码、入口与构建见[系统入口](../README.md)。历史验收记录、HTML原型和截图已归档到仓库根的本地忽略目录 `.local-dev/`，用于本机查阅，不作为运行资源或提交内容。

本文保留已经确认的单条崩解度、安全区保证、实时抽卡、形态差异与成功施法适应机制。术式语法、报价系数、研究流程和新UI是本轮选择的设计方案；数值标定属于设计默认，需要后续实战平衡。

## 一、玩家实际在研究什么

玩家研究一套世界内的“术式学”：怎样组织作用、怎样承载作用、失稳怎样破坏控制。掌握的规律能够用于改造已有法术，预测新组合，并迁移到不同形态与用途。

完整循环：

```text
取得样本或观察现象 → 提出解释 → 制作基准与变式
     ↑                              ↓
带到实战后发现新问题 ← 归纳规律 ← 测量并比较结果
```

一个命名法术是一份成熟的术式方案。研究产物既可以是新方案，也可以是有适用条件的规律，例如“分流如何分配作用量”“某形态为什么更容易控制聚束”。

“科学”要求同条件下规则一致、观测能复查、解释能被反驳。危险区中具体抽卡结果仍随机，可研究的是相同条件下的概率规律，不保证每次试验结果完全相同。

## 二、术式的组成

### 2.1 三层构成

| 层 | 决定什么 | 例子 |
| --- | --- | --- |
| 作用核 | 改变什么性质 | 热蚀、降温、修复、附着、构成、侵蚀、连接 |
| 载形 | 怎样把作用送到目标 | 自体、接触、投射、区域、锁定 |
| 控制结构 | 怎样分配、约束、延迟与结束作用 | 分流、汇合、储存、约束、跨越、转化 |

蓝图记录这三层结构及其参数；名称由玩家命名，系统同时保留标准结构摘要。改名称不改变法术身份、熟练度或冷却。

### 2.2 作用核与原有法系的对应

| 法系 | 新体系主要作用核 | 基础作用 | 可研究的结果 |
| --- | --- | --- | --- |
| 火焰 | 热蚀 | 造成热蚀伤害，适配燃烧 | 瞬时作用与持续燃烧的分配 |
| 寒霜 | 降温 | 减速、冻结趋势及适配的冰壳 | 控制强度、覆盖与维持 |
| 月辉 | 修复 | 治疗或适配的防护 | 单体恢复、分流支援与作用反转 |
| 诅咒 | 附着 | 把有生命周期的标记附着到目标 | 持续、传播、触发条件 |
| 召唤 | 构成 | 建立并维持允许的召唤物 | 数量、单体承载与寿命 |
| 虚无 | 侵蚀 | 消减允许侵蚀的状态或生命 | 作用速度、目标条件与代价 |
| 空间 | 连接 | 建立有限距离内的空间联系 | 目标端点、连接距离与释放位置 |

每个作用核必须声明实际支持的载形、参数和转换。界面只允许构建有行为实现的组合，不把“写入符文”当作自动创造所有技能。

初始载形许可表如下，后续扩展需要逐项增加适配：

| 作用核 | 自体 | 接触 | 投射 | 区域 | 锁定 |
| --- | --- | --- | --- | --- | --- |
| 热蚀 | — | ✓ | ✓ | ✓ | — |
| 降温 | — | ✓ | ✓ | ✓ | — |
| 修复 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 附着 | — | ✓ | ✓ | — | ✓ |
| 构成 | — | — | — | ✓ | ✓ |
| 侵蚀 | — | ✓ | ✓ | ✓ | — |
| 连接 | ✓ | — | — | — | ✓ |

连接核的自体载形表示以自身为被移动对象，仍需合法端点和距离条件，不等于无目标任意传送。构成核的汇合需要先定义集中构成的合法对象；自体载形不允许无目标的多路分流。

### 2.3 控制符文的统一含义

| 控制 | 规则 | 收益与代价 |
| --- | --- | --- |
| 分流 | 将既有作用量分配给多条通路 | 覆盖增加；每路所得下降，维持每路原强度需增加总投入 |
| 汇合 | 把作用集中到更小的目标或空间 | 局部作用密度提高；覆盖与命中宽度下降，控制负荷增加 |
| 储存 | 建立有限容量的待释放结构 | 获得延迟与触发选择；占用构型容量并承担储存损耗 |
| 约束 | 限制作用方向或边界 | 减少对应偏移；增加构型负荷或准备要求，不能让危险区无条件免疫失稳 |
| 跨越 | 延长传递路径或连接距离 | 可作用得更远；传导代价随路径增加 |
| 转化 | 在显式允许的作用类型间转换 | 获得新用途；要求转换关系及损耗，没有适配关系就不能构建 |

“约束”承接原稳定符文的控制含义，不等同身体稳定度S。恢复类符文属于修复作用的组成，不自动降低身体崩解度，避免生成无限自补循环。

同一控制在投射、治疗、召唤和以后世界法阵中保持语义一致，但只作用于各作用核公开的能力。重复控制采用有上限、有损耗的组合规则，不产生无限分支或无限延迟。

### 2.4 构建规则

1. 术式为有限的有向作用通路，每个分支必须有允许的终端。
2. 控制节点检查输入、输出类型；类型不匹配时给出具体诊断。
3. 空控制位表示直通，不收空位费用，不要求为了填满外环装入无用符文。
4. 分流后可以再汇合；结构允许时结果可以回到集中输出，但额外控制与损耗不会消失。
5. 旋转或镜像若不改变通路语义，应识别为同一构型；不能靠换摆放起点刷新熟练度或冷却。
6. 构建合法性保持确定性。结构不成立时在编辑或起手预检拒绝，不依赖施法抽卡让坏结构偶尔成功。

首轮媒介的设计默认上限为6个控制节点、6路终端、1次储存与1次转换，约束最多2层；禁止未声明终止条件的循环。超过容量时报告具体超限，不自动截断结构或随机丢失节点。容量属于可配置的媒介限制。

新体系取消“先匹配唯一命名法术答案，再只改外圈加成”的强制结构。已有命名方案可以作为样本和可靠起点，新蓝图通过已实现的模块语法解释。

固定配方、外圈规则与法阵存档保留；试验田原法术书的支付已改为本体系的崩解，见[书加成映射](旧法术书接管与加成映射.md)。

## 三、作用量与代价

### 3.1 作用量不是第二条资源

作用量U描述本次术式试图组织多大的作用，由施法前选择的规模等参数决定。它是本次方案参数，不是玩家存储、回复或消耗的能量条。

不同作用核把U换算成各自的效果单位。伤害、治疗、召唤数量和空间距离不直接互相等价，必须通过各核的能力与报价模型转换。

### 3.2 报价关系

设计默认采用以下可研究的模型骨架：

```text
正常负担 Q0 = a × U + b × U² / (T + 0.5) + 1.5 × D + 2 × K
实际负担 Q = 身体适应倍率 A × Q0
```

T为选定准备秒数，D为归一化路径负荷，K为控制结构负荷。不同作用核分别配置a、b及其路径计算方式；复杂的面积、持续和召唤维持等通过对应适配器折入U、D或独立收费项。

首轮演算中的热蚀核取a＝6、b＝18，默认路径32格，即D＝2。该数值只供设计原型比较，不代表已经平衡的游戏数据。

原型为各作用核设置如下设计默认，用于展示独立报价；它们都还需要对应效果单位与实战标定：

| 作用核 | a | b | 路径负荷D |
| --- | ---: | ---: | --- |
| 热蚀 | 6 | 18 | 距离÷16 |
| 降温 | 5 | 15 | 距离÷16 |
| 修复 | 8 | 20 | 距离÷16 |
| 附着 | 4 | 12 | 距离÷16 |
| 构成 | 10 | 30 | 距离÷16 |
| 侵蚀 | 12 | 36 | 距离÷16 |
| 连接 | 14 | 42 | (距离÷16)² |

原型的直通、三路分流、聚束汇合分别取K＝0、2、2.5；身体适应完成后的保留比例分别为50%、40%、35%。这些是同一投射族的比较样本，不能据此代替全部法术和结构的独立配置。

这个关系使输出有基础代价，快速组织大作用有额外负担，传导和复杂控制也有代价。延长准备可降低快速组织附加项，但不能把实际作用的负担降为0。

### 3.3 参考投射术式的作用预算

为使分流与汇合可以真实比较，首个热蚀投射族约定每次总作用预算为9U：

| 构型 | 作用分配 | 可研究的区别 |
| --- | --- | --- |
| 普通投射 | 直接目标最多6U，附近目标合计最多3U | 同时兼顾直接命中与小范围扩散；未使用预算不返还 |
| 三路分流 | 每路最多3U，三路总计最多9U | 更宽覆盖，每路更弱；多路控制增加K |
| 聚束汇合 | 单个窄束目标最多9U，无周边扩散 | 单体集中，碰撞与覆盖宽度更小；集中控制增加K |

实际伤害继续受目标防护、免疫、碰撞与既有保护规则影响。命中同一目标时不为研究而移除正常无敌帧。记录区分“到达目标的作用量”和“真实扣除的生命／吸收量”。

不能把三路分流做成每路都携带整份9U。若要求三路各有原来的总作用，必须提高U并支付对应Q。

### 3.4 准备方式的取舍

短准备提高快速组织附加负担；长准备有更大起手空窗，也经历更多次偏移检测。失败只在起手抽一次，延长准备本身不增加失败抽签次数；实际 Q 的变化仍改变该次失败概率。

报价在起手锁定。完成准备后额外等待手动释放，不重新降低Q。持续或储存法术的费用阶段必须单独声明，不把同一份效果先后重复计费。

## 四、身体承载与实时检测

### 4.1 唯一的身体资源条

```text
C：当前累计条值
S：当前形态身体稳定度，即安全阈值
E = max(0, C-S)：当前超额崩解点数
```

施法逐步增加C，停手等待后自动降低C。稳定度表示安全空间，不单独保存一份会扣减的稳定资源。

失败抽签使用起手预计完整支付后的 C₀＋Q；若该值不超过起手 S，失败率为0。偏移与反噬继续看发生时的实际 C；实际 C≤当前 S 时无随机偏移或超额反噬。因抽签使用预计负荷，预计将越线的施法可能在实际 C 尚未越线时提前失败。射程、目标合法性、遮挡和实际碰撞规则仍正常执行。

### 4.2 一次失败抽签与实时偏移

本节由 `neomagic.4` 的最新确认取代原先每10 tick重复抽失败的规则。

- 起手在 tick 0 用 `C₀＋实际Q`、起手形态／书的安全阈值及失败修正，计算整次失败概率，只抽一次。
- 抽中失败时，再均匀抽一个失败时刻。设 L 为不可打断释放界限，则取整数 tick `0…L−1`；不是只从10的倍数中选择。
- 运行时每次施法只建立一个随机源；失败判定只消耗一次随机抽取，抽中失败才额外抽一次失败时刻。之后逐 tick 只比较预定时刻，不重新计算失败率或重抽失败。每10 tick的实时风险只用于偏移，普通支付 tick 不重建形态参数，不扫描或复制整份检测历史。
- 具名法术取实际准备结束和特殊锁定点两者较早者；没有特殊锁定点时 L＝准备时长。爆裂的界限为540 tick，领域为200 tick（以当前配置及法术返回值为准）。
- 瞬发在 tick 0 全额支付，并在产生效果前抽签、失败或成立；不会为它人为增加读条。
- 渐进支付仍每2 tick按进度结算，结束补齐尾差。非瞬发 tick 0 不预收全额。到选定失败时刻时，保留当时应付且已结算的部分，未支付部分不补扣，进入完整 CD。
- 偏移仍从0 tick开始每10 tick按当时实际 C、实际总 Q、当前形态修正检测并累加。35 tick准备在0／10／20／30检测偏移；若抽中了17 tick失败，会额外记录17 tick的失败事件，但不在17 tick额外抽偏移。
- 抽签后升高／降低 C 或等待更久均不重新抽失败；普通中断、变形重置、目标合法性和效果自己的异常结果仍按各自规则处理。
- 进入不可打断阶段后，不再发生这一项抽签导致的施法打断。已成立的弹体或持续效果也不再抽失败。

### 4.3 连续概率模型

系数保留当前默认值，不增加概率档位：

```text
E失败 = max(0, C₀ + 实际Q − S₀)
P整次失败 = clamp[0,1](0.03 × (E失败/10)^1.3 × (Q/20)^0.7 × F起手形态 × F控制)

E当前 = max(0, 当前C − 当前S)
p当前偏移 = clamp[0,1](0.08 × (E当前/10) × sqrt(Q/20) × J当前形态 × J控制)
```

轻、中、重只是描述标签；E＝2、10、19分别按真实值计算。E大于60后仍可上升，整次失败概率可达到100%。每个形态继续有独立的安全阈值、失败与偏移修正。

整次失败率就是起手的一个概率，不再把多个检查点相乘。约10%仍是典型情境的平衡参考。准备时长只通过报价 Q 改变失败率，不通过重复抽签增加失败率。

例如 S＝80、起始 C＝70、Q＝25、准备40 tick，预计完整支付后 C＝95、E失败＝15，中性修正下本次失败抽签约4.087%。若抽中失败，失败时刻均匀取0至39 tick；若取17 tick，只支付至16 tick的进度。实际偏移仍按0／10／20／30／40时点的实际 C 检查，不改变玩家镜头。

失败率和预计负荷可显示给玩家，预先抽定的成败结果与失败时刻只存在服务端；实验记录在事件发生时记录结果，不提前泄露时刻。

## 五、形态如何参与研究

每个形态分别配置S、失败修正、偏移修正，以及需要时的作用核／控制适配。不能只改安全阈值而把超额后的抽卡全部做成相同。

首轮设计原型选用三份标定样本：

| 样本 | S | 热蚀失败修正F | 偏移修正J | 额外适配示例 |
| --- | ---: | ---: | ---: | --- |
| 人类 | 100 | 1.00 | 1.00 | 中性对照 |
| 荧光幼灵 | 80 | 1.15 | 0.85 | 方向控制较好，热蚀承载更吃力；其他作用核单独标定 |
| 使魔 | 200 | 0.80 | 0.90 | 聚束失败修正再乘0.80，分流再乘1.10 |

这是验证形态差异的设计默认，不宣称已确认全部形态平衡。正式实现时各形态ID均应有明确标定；未标定形态应显示所用参考配置，不伪装成已经具有独特适配。

切形态直接重置C并更换S与修正。已有CD、身体适应及实验记录不因C清零而消失。施法准备中变形，设计默认中断当前会话后重置身体负担，不能用旧身体报价继续完成。

## 六、失稳、反噬与普通中断

### 6.1 异常由控制失效产生

| 结构职责 | 对应异常 |
| --- | --- |
| 指向与锁定 | 累积偏移、锁错目标、锁定失败 |
| 多路组织与维持 | 召唤或输出数量减少、部分效果减弱 |
| 修复量与作用方向 | 治疗减少、治疗失败、治疗转为伤害 |
| 连接位置与长度 | 前方错误落点、距离减少、可能危险的传送 |

各作用核声明自己的异常集合与概率修正，不从一个与结构无关的通用惩罚池里随便抽。危险传送不强行吸附回安全点，但仍满足有效维度和坐标等引擎要求。

错误目标与治疗反转仍走正常伤害／目标保护校验。异常不能绕过PVP开关、领地或白名单。

### 6.2 完全失败

效果不成立，进入正常完整CD，保留已支付C。反噬沿用失败时的实际超额 E：E>0时产生伤害事件，实际 C 尚在安全范围内的提前失败不额外附加超额反噬。首轮候选伤害为`1.5＋0.05E＋0.02Q`生命值，最终减免方式由伤害类型标定。

保留魔力失调的5秒禁施法／减速15%，散解崩除的15秒禁施法／减速35%／失明方向。原讨论的45%表示失败后附加轻状态的基准概率，不是法术本身失败率。

严重状态的概率与强度随E继续增长。E>60后可以出现持续身体损伤并致死，不保留最后1点生命值；停止施法或用药降低C，不默认清除已存在的严重状态。

状态选取采用互斥结果或明确覆盖规则，不让轻重减速和禁施法时长无说明地累加。具体状态曲线与伤害标定属于后续平衡表。

### 6.3 普通中断

非法目标、起手条件不足等在施法前拒绝，不收费、不抽崩解。已开始后主动取消、换施法载体、完全定身或其他规定中断保留已支付部分，不额外当作失稳反噬。

新体系普通中断CD的设计默认是正常CD的50%，最低10 tick；完全失败始终完整CD。效果已经成立后的取消或外部清理遵循该效果的生命周期，不撤销过去结果。

不引入乱键位、强转镜头、施法变身或死亡生成野生幻形生物。

## 七、恢复、补给与生命周期

首轮恢复默认：最近一次支付后等待3秒，之后每秒降低5点C；施法准备期间暂停自然恢复。数值可独立配置，不与旧蓝条共用状态。

恢复最低到0，先降回S便回到安全范围。死亡后设计默认C归零，适应和研究记录保留；退出期间不按真实时间离线消减C，重登不会直接洗掉剩余恢复等待。

月尘药水用于降低同一条C，保留试管快且少、瓶装慢且多、喷溅可支援的分工。它不永久提高S，不增加研究或熟练度，不自动净化反噬。用量和配方另列平衡数据。

冷却与状态独立于身体C。换形态重置C不重置冷却；跨维度不清空C；规则更新后保留历史实验版本，使旧结果仍能被解释。

## 八、研究如何推进

### 8.1 起步与发现

研究笔记提供入门的来源、一个作用核与基础载形。其他控制或作用核从术式样本、遗迹刻纹、研究手册及可观察现象中获得线索。

解析样本得到结构片段、已知作用和待解释现象，不直接自动填出唯一正确摆法。玩家可以保存可靠样本作为基准，在其上改一个变量。

### 8.2 对照实验

一次记录至少包含：蓝图与规则版本、所选参数、形态和S、起始C、正常与实际Q、支付进度、每次检测条件、累计偏移、效果结果、实际命中及作用／伤害量。

比较时明确检查形态、起始负担、目标、距离和准备参数。条件不同时允许比较，但显示具体差异，不自动给出“已证明”的结论。

结构规律主要在安全区验证。危险区数据可以来自正常战斗记录，不强迫玩家反复自伤才能解锁法术。

### 8.3 笔记的三种内容

- **观察**：本次实际发生的结果，服务器记录，不能被玩家手写替换。
- **假说**：玩家对现象的解释，可编辑，允许被反驳。
- **结论**：引用基准、变式及适用条件的归纳；保留证据来源，不把一次随机结果当作确定因果。

样本数量与当前模型估计分开显示。“三次中失败一次”只显示观察次数，不宣称未来精确失败率33%。

### 8.4 知识共享

图纸可以分享结构与结论，接收者仍需相应元件、媒介容量和制作材料。身体适应、个人经验及物品不会随读图复制。

基础规律保持一致；如果以后改变不同世界的符文外形或材料参数，生成后固定并记录，不能每次试验重新随机一套规律。

知识以后可用于警戒阵、防护阵、储存装置和遗迹机关。这些用途遵循同样的符文含义，不把研究限制为一次法术解锁手续。

## 九、成长与法术身份

### 9.1 两种成长

研究成长增加构造、观测、诊断与预测能力；身体适应通过成功施放降低对应法术的实际Q。失败仍能留下研究资料，但不增加身体适应。

法术身份由作用核、载形及主要控制结构决定。改名称、旋转等价结构或小幅调参数不重新练习；主要结构变化形成有继承关系的变式，继承比例单独配置。

### 9.2 难度与消耗下限

身体适应按蓝图谱系及工作区间记录。低负担练习主要覆盖低工作区间，高输出、复杂结构需要对应难度的成功施法才能充分适应。

高阶魔法所需进度更多或单次所得更少，不能只按总点击次数全系一起成长。练熟后一般保留相同构型、输出和准备参数下正常Q的35%–50%，具体下限按法术标定。

### 9.3 阶次的含义

术式阶次主要描述结构与控制能力：单路作用、分支控制、储存触发、复杂转换与多终端协同。媒介容量与已掌握的原理决定能构建多复杂的结构，不默认每升一级再给一套全局伤害乘数。

实际威力仍由作用量、组织和目标条件共同决定。书等级与法阵仍归书；玩家施法等级每级增加50安全阈值，书的等级和容量法阵不再增加承载上限，恢复增长仍转为崩解恢复倍率。玩家经验门槛依次500、1000、1500，此后每级720；安全0～N、危险N～2N，恢复延迟6秒。自建结构的身体适应仍独立记录。

## 十、完整玩家入口

| 入口 | 职责 |
| --- | --- |
| 术式研究台 | 解析样本、编辑蓝图、比较方案、管理研究笔记 |
| 观测笔记 | 查看记录与结论，携带或分享蓝图 |
| 导引杖／新体系施法媒介 | 装载已制作的蓝图，选择输出与准备方式并施法 |
| 术式观测靶 | 提供明确测量条件，区分入射作用量与真实生物伤害 |

载体等级首先限制结构容量，不替代身体稳定度。研究台试摆免费，制作有效媒介与蓝图才消耗材料；纯预览不支付身体负担、不授予身体适应。

实际施法由服务器复核蓝图、参数、媒介、控制状态、冷却及规则版本。前端不能自行宣布成功、增加适应或修改C。

## 十一、新研究UI

研究UI重新组织为四页，详见[UI设计说明](UI设计说明V2.md)：

1. **观测**：样本、现象、最新记录与待解释问题。
2. **构式**：左侧元件库、中央术式盘、右侧参数与身体承载，底部保存基准／复制变式／验证结构。
3. **实验**：基准与变式的条件比较、真实结果、每次检测时间线及偏移分布。
4. **笔记**：观察、假说、结论及引用的实验记录。

日常编辑优先呈现作用规模、组织方式和准备节奏。公式系数、规则版本等只放高级诊断，不把开发字段挤进玩家操作流程。

界面使用低亮度深色底板、金色术式线、青色观测标记与明确危险色；文字独立渲染，按钮与数值保持缩放可读。安全、危险与合法性都同时有文字说明，不仅靠颜色。

## 十二、实现边界与验证次序

本设计适用于独立试验田，不修改原项目 main。根据最新授权，试验田直接接管原法术书、卷轴及快捷键的支付与风险，保留书及原有加成；原蓝条不再用于施法。详见[书加成映射](旧法术书接管与加成映射.md)。

实施可以分批，但最终交付目标是上述完整系统。推荐先用热蚀投射族验证模块语法、三种组织、三种形态、实时检测和对照记录，再按同一接口接入其他作用核；这只是验证顺序，不把整套系统限制为一个投射原型。
