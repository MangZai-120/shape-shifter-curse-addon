# 新法术系统实现与验收记录

当前测试包：`8.0.0-neomagic.4`。本轮失败规则见本文末尾“单次抽签”节；旧版本记录保留为历史证据。

日期：2026-10-27。项目：SSCA新法术系统试验田，分支`neomagic`。

## 规格顺序与范围

本次按用户明确授权进入Minecraft实现。已经确认的资源、实时抽卡和形态规则优先；完整玩法以[系统设计V2](SSCA新法术系统完整设计V2.md)为主，早期方案和原始聊天作为历史依据。

V2当前范围的独立施法、七作用核、六控制、身体承载、研究、成长、药水及四页界面均有生产实现。原文否决的强制变身、死亡生成野生幻形生物不实现；原文明确列为未来扩展的警戒阵、世界储能装置和遗迹机关不属于当前功能。

HTML原型仍是设计计算器。实际游戏使用Minecraft原生界面、实体和服务端数据。

## 旧书、卷轴及快捷键接管（neomagic.3）

[接管与加成映射](旧法术书接管与加成映射.md)是最新入口规范：法术书保留，原施法键与独立卷轴使用同一条崩解；容量与恢复奖励分别转为安全阈值与崩解恢复。下面的导引杖研究流程仍可使用。

## 游戏内使用

1. 合成**术式研究台**、**观测笔记**、**导引杖**和需要的**术式样本**。配方位于独立数据目录；地牢、废弃矿井、要塞图书馆也有机会提供样本。
2. 在研究台附近使用样本，解析作用核、载形和控制。起始已掌握热蚀与投射，样本不会直接生成唯一正确术式。
3. 使用研究台打开四页界面。在“构式→元件”选择作用核和载形，按顺序加入控制；在“参数”设置名称、作用规模、准备时间和路径。
4. 在“术式盘”检查结构与作用预算，在“承载”查看当前崩解、安全阈值、实际报价和当前单次风险。保存基准后再调整变式。
5. 用纸×1、紫水晶碎片×1制作蓝图，再点击“装载导引杖”。背包里必须确有对应蓝图及导引杖。
6. 使用导引杖施法；潜行使用取消准备，或触发已储存结构。储存最多10秒，逾期失效。
7. 用观测笔记查看真实记录；实验页选取A/B，检查条件差异、检测时间线与偏移样本分布，再在笔记页写假说和带条件的结论。
8. 制作蓝图时附带当前结论和引用的原始证据。分享蓝图不复制身体适应，不绕过接收者的元件知识要求。

创造模式可在“术式学研究”物品栏取得物品。具有管理员权限时，`/neomagic kit`提供试验材料，`/neomagic research_all`掌握元件，`/neomagic reset_burden`清空测试负担。这些不是普通生存成长途径。

## 试验默认数值

这些是本轮为可运行试验补齐的默认值，不宣称已经完成实战平衡。已确认的单条资源、安全区保证、实时检测及形态重置规则不因默认数值调整而改变。

- 准备0–80 tick；作用规模0.5–4；普通路径最多32格，跨越后64格。
- 最多6控制节点、6路终端；储存／跨越／转化各1次，约束最多2层。当前分流一次为三路；不允许第二次分流导致9路超限。
- 分流分配总作用，汇合集中且缩小命中宽度。分流再汇合保留90%，储存保留85%，转化保留80%。支持热蚀↔降温、修复→侵蚀转换，输出载形仍要合法。
- 热蚀投射族采用V2的9U总预算，普通直接6U、附近合计3U，分流三路各3U，聚束单目标9U。实际无敌帧、护甲与伤害保护仍生效。
- 修复将作用预算转为治疗；寒霜为减量伤害加减速，附着为减量伤害加有期限虚弱；侵蚀为伤害及有上限的吸收消减。三者具体换算在效果适配器中明确，不宣称等价的数值必定有相同实战价值。
- 构成使用有主人、有寿命的狼形构成物，10秒后清理，数量、生命和攻击承载分享总预算。持久化后重新加载的过期构成物会清理，不能变成无主野生生物。
- 空间作用按规模、路径、保留系数与异常衰减计算位移；分流锁定术式可将位移分配给多个目标。危险端点不会被自动吸附回安全点。
- 最近支付后等待60 tick，之后每tick降低0.25 C（每秒5点）；准备期间暂停恢复。退出不按真实时间离线恢复。
- 完整CD默认`60＋20×术式阶次`tick；普通中断50%，最低10 tick。起手锁定本次正常CD，重载配置不会改写正在进行的会话报价和CD。
- 同结构身份不因改名或微调参数刷新适应及CD。工作区间分为≤1、≤2、≤3、≤4，成功一次增加1，默认所需`20×阶次²`；高区间成功可训练更低区间，低区间不能练满高区间。
- 直通／分流／汇合默认练熟保留50%／40%／35%代价。异常后效果成立算完成；完全失败、取消及储存失效不增加适应。结构发生主要变化后作为独立法术训练，当前不自动继承旧结构进度。
- 失败反噬候选为`1.5＋0.05E＋0.02Q`生命值；轻状态5秒／−15%，重状态15秒／−35%及失明。重度持续损伤可以致死。轻重状态明确覆盖，换形态不自动净化已有状态。
- 月尘试管16 tick饮用、降低20 C；瓶装40 tick、降低60 C；喷溅立即投掷，半径4格、中心最多35 C并随距离衰减。使用原版未处理月尘参与合成，不回复旧蓝条。
- 实验历史保留32条，优先保留笔记引用。每条保存各次实时检测、最终累计偏移、真实到达量、生命／吸收变化及至多32份目标测量明细。

## 配置与存档

默认规则：[`data/ssca_neomagic/rules/defaults.json`](../src/main/resources/data/ssca_neomagic/rules/defaults.json)。包含57个当前注册形态的显式参数、七核独立报价和恢复参数。未识别形态使用明确标注的参考配置。

`spells`可按`Blueprint.identity()`覆盖单个术式，或以`身份#工作区间编号`覆盖档位；可配置`cost`倍率、`floor`（0.35–0.50）、`cooldown` tick及`mastery`所需进度。缺省采用V2关系，不给所有法术强塞同一固定负担。

玩家状态保存到世界`data/ssca_neomagic.dat`，与旧mana、旧书经验及旧冷却表分离。长实验记录按UTF-8字节数组保存和同步，避免NBT单字符串64KiB限制。记录保留原规则版本，调整配置不重写历史结果。
