# 试验田的法术书接管与加成映射

2026-10-28，当前版本 `8.0.0-neomagic.13`。本说明取代早期“新旧施法入口互不接管”的限制，仅适用于 `neomagic` 试验田；原项目 `main` 独立维护。

## 玩家实际使用

月尘魔法书保留：仍可佩戴、装入卷轴、选择档位、用原施法键和七个直达键施法。普通右键保留书内配置，潜行右键打开新研究记录；寄生果蝠的播种手势优先。书等级、卷轴槽、法阵槽、玩家施法成长、经验奖励、符文、卷轴品质及磨损效果继续生效。

书内法术、独立卷轴和导引杖统一增加玩家的 `C`。旧书的 `Mana` 数据不再承担施法支付，空蓝不会拦截，也没有因蓝量不足而触发的三连按降档。手动选档仍保留，可主动选择更低的崩解代价。书内法术和导引杖不能同时准备。原生形态技能继续使用各自的形态能量。

稳定度像素条在装备书、手持书／卷轴／导引杖或 C 非零时显示，拥有独立的客户端开关、九宫格锚点和X/Y偏移。原书只保留三槽选择器、名称和冷却，不再附带崩解小条。统一定位入口：Mod Menu → 附属配置 → HUD位置与显示，点击稳定度条后调整；点击空白处收起面板。左上“崩解度debug条”在客户端配置中单独开关。配置书页显示崩解与安全阈值，不显示旧蓝量作为可支付资源。注魔台保留升级和六芒星配阵，显示安全与崩解加成；不再自动烧燃料给已退役的蓝条充能。

## 加成映射

| 原加成 | 新效果 |
| --- | --- |
| 伤害、治疗与同系／对立系威力 | 保留原公式；随机偏移造成的衰减在释放时叠加 |
| 冷却、品质磨损、形态亲和与符文冷却 | 保留原公式和共享冷却，换槽／换书不绕过 CD |
| 原基础耗蓝、选档倍率、法阵耗蓝与符文耗蓝 | 作为本次基础崩解报价，再乘该法术的身体适应减免 |
| 书等级与增能法阵的容量增长 | 不再增加玩家安全阈值或危险上限；书升级仍解锁槽位并保留恢复成长 |
| 玩家施法等级 | 所有施法入口成功后均获得玩家经验，每级增加50安全阈值；依次需要500、1000、1500经验，此后每级720 |
| 书等级与回息法阵的回蓝增益 | 转为同一条 C 的自然恢复倍率；仍须等待恢复延迟 |
| 回能法阵 | 保留形态能量的触发与汇率，将回书蓝改为降低 C；施法期间暂停 |
| 命中返蓝、风行、月相、共生、血契、播种 | 原触发、预算及防重规则保留，实际返还改为降低 C |
| 书经验、经验法阵、命中经验 | 保留原结算；身体适应另按单个法术记录，失败不获得适应 |

安全阈值公式：`N = 当前形态基础安全值 + 玩家施法等级 × 50`。安全范围0～N，危险范围N～2N，超过2N进入极危。风险仍连续读取当前C、实际Q和形态修正；曲线超额负荷按 `(C−N)/N` 归一化。书升级保留原600／900经验与材料规则，但不增加N。未满级书和玩家可同时获得施法经验，满级书只给玩家成长。独立卷轴、自建术式与储存后实际释放也计入玩家成长。恢复延迟为停止支付后6秒（120 tick）；变形不清玩家等级。

导引杖施放的自建术式在装备书时也读取对应元素的威力、消耗和冷却法阵加成；释放用的威力与 CD 在起手时锁定。安全阈值随当前装备实时变化。原有书内符文仍随原卷轴结算，自建蓝图使用自己的控制结构。

## 支付与异常

所有入口使用同一个单次失败抽签：起手按 `C₀＋实际Q` 预计完整支付后的超额负荷，结合起手形态及玩家的 N 和失败修正，只抽一次。抽中后，在不可打断界限之前均匀选择一个整数 tick 失败；失败点可以不是10的倍数。普通法术界限为准备完成，特殊法术取准备结束与特殊锁定点的较早者，瞬发在0 tick付费并判定。0–20／21–60不作为概率档位。

偏移仍在0／10／20…读取实际 C 和当前形态，支付仍每2 tick结算。700 tick爆裂在起手抽一次失败，抽中时必须在540 tick锁定点前失败；其准备过程的偏移检查最多71次。准备结束后继续按住不重复支付或再抽失败，但仍检查偏移。

失败保留已支付 C，未支付部分不补扣，进入完整报价 CD。抽签一旦完成，药水降低 C 或后来 C 升高均不重新抽失败。反噬在会话清理和 CD 结算后，按当时实际超额施加。目标失效、锁偏和召唤归零等效果自身的异常不属于追加一次失败抽签。

投射与射线偏移在构造效果时消耗累计角度，之后恢复服务端视角；空间传送通过落点偏移和距离衰减实现，避免传送包将偏移角写入玩家镜头。月相的锁定可落空或选中其他可见目标。月华治愈可能衰减或反转伤害，反转后不附带净化；召唤月灵可能减少数量或归零。回溯和口袋空间的锚点失稳会直接失败，不继续保证抵达原锚点。

效果已经释放后，不再对该效果抽崩解卡。持续法术在开始产生效果时结束准备检查；其原持续、停止和使用次数规则保留。

## 记录和验证边界

书内记录使用独立的具名法术 ID，例如 `spell:ssc_addon:lunar_mend`，同系不同法术不会混练。高品质练习所需次数更多，默认最终保留普通代价的 35%–50%。原书经验仍存原书，身体适应与 C 存玩家的新状态文件。

现有具名法术记录实际支付与逐次风险，不将未接入新计量器的后续伤害／治疗显示成零测量值。自建术式保留原有真实效果测量。对照统计区分法术 ID、报价、形态安全配置和准备时间。长时间持握最多保留起手及最近 511 次检查，被省略的中间次数会明确标注；正常 700 tick 读条保留完整记录。

自动验证：`neoMagicWorldTest -PneoBookCutover=true` 在临时真实 ServerWorld 中检查空蓝书、饰品装备、独立卷轴、逐 tick 支付、实时失败、完整 CD、经验及适应、长读条与记录边界。客户端按键由原处理器发送到同一个服务端入口；该测试不等同于真人客户端键盘、音效、Curios 或 LAN 验收。

施法推进的失败抽签只在起手执行一次，命中后再抽一次失败时刻。每个会话复用自身随机源；后续10 tick事件只处理实时偏移。研究记录与会话共用同一份有界检测列表，避免每 tick扫描和复制全部历史；检测字段与保存格式保持兼容。
