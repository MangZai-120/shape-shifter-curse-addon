# 新法术研究与HUD界面设计

2026-10-28，当前版本 `8.0.0-neomagic.13`。完整机制见[完整系统设计](SSCA新法术系统完整设计V2.md)，法术书沿用关系见[接管映射](旧法术书接管与加成映射.md)。

## 研究工作台

游戏内由 `NeoScreen` 实现观测、构式、实验、笔记四页。共同使用原生字体和按钮，窄屏通过子面板切换呈现信息。

- 观测：选择样本，查看已观察事实、候选解释与适用条件。
- 构式：组合来源、作用核、载形、控制与参数；结构错误标记具体节点。展示当前C、S、实际Q和预计完整支付后的负荷。
- 实验：对比条件与真实测量结果。时间线只记录已发生的失败，不展示预定失败时刻；样本量不足时明确标注。
- 笔记：区分观察、假说、结论，并保留适用条件与记录引用。

保存、制作和施法均由服务器复核。客户端预览不写真实C、研究进度或材料。

## 独立稳定度条

主条外框为97×16，带数值区域占97×24；使用玩家确认的玻璃边框和修改后的左侧原图。底座保持干净灰色，槽内为青蓝→橙→红的像素杂色。数值使用一像素深色描边，保持状态色并适配高亮背景；矩形像素和调试面板使用原生批量绘制，避免逐像素提交。

- 数字为当前C／有效S；实色为已支付的C，细白线为当前有效S。
- 淡斜刻纹和 `＋` 数值表示尚未支付的部分；准备中只使用 `Q−Paid`，避免重复计算。
- 青灯表示预计支付后 `C＋实际Q≤S`；红灯表示预计越线；未选法术时为灰灯。灯不表示抽签结果。
- N等于形态基础安全值加玩家施法等级×50，法术书及其容量法阵不再增加承载上限。卸书保留C和玩家等级，变形只重置C。
- 轨道显示0～2N：0～N安全，N～2N危险，大于2N极危；超过后显示溢出箭头，真实C继续增加。白线按形态固定，基础100的形态在玻璃轨道50%，基础200在80%；玩家升级只改变两段刻度，不推动白线。
- 阶段图标分别表示支付、不可打断、恢复等待、恢复、已发生失败与重置。客户端不接收预定成败或失败tick。

原月尘书只保留三槽、法术名及CD；原形态蓝条使用原本位置。三个HUD不会共用坐标。

## 统一HUD位置编辑器

入口为 Mod Menu → 附属配置 → “HUD位置与显示”；SSC客户端配置页的同名入口也打开同一页面。

1. 进入页面时只显示HUD预览和右上角关闭叉号，没有底部公共按钮或中间调整框。
2. 点击本能条、形态能量条、CD栏、法术书、蓄力条、SSC法术栏或稳定度条，显示且只显示该目标的锚点、X/Y、显隐和重置设置。
3. 点击另一个目标立即切换；点击画布空白收起面板。面板控件本身不会被当成空白，也不穿透点击后方HUD。
4. 继续支持拖拽、吸附、方向键逐像素微调；Shift自由拖拽或10像素方向键微调。重叠时按预览绘制层级命中。
5. 隐藏的HUD仍保留编辑手柄，可以选中后重新开启。单个HUD的重置按钮仍位于该目标的调整框中。
6. 面板只创建当前目标的控件，切换时清除旧焦点与控件引用。窄屏保留完整按钮、输入框和退出路径。
7. 点击右上角叉号或按Esc弹出“保存并退出、撤销并退出、取消”。保存持久化并返回上一页；撤销恢复进入时全部位置与显隐；取消或再次按Esc返回编辑，保留当前目标和未保存调整。没有改动时也显示相同选项。
8. 退出弹窗打开时屏蔽底层HUD点击、拖拽与方向键调整；点击弹窗外不会误选HUD。

稳定度条的独立配置键保持 `showNeoStabilityBar`、`neoStabilityBarPosType`、`neoStabilityBarPosOffsetX`、`neoStabilityBarPosOffsetY`，默认锚点7、偏移(16,−88)。

## 崩解度debug条

左上详细面板标题为“崩解度debug条”，通过客户端配置中的同名开关控制，配置键为 `showDisintegrationDebugBar`。关闭它不影响稳定度条、网络状态、施法或恢复。
