# SP 形态概述

**SP 形态（Special Form）** 是 SSCA 的核心进阶形态体系。它们不是简单数值增强，而是为原形态重写战斗循环：有的围绕资源条，有的依赖召唤物，有的专注控场、隐身、治疗或百分比爆发。

***

## 玩法分组

### 资源循环型

SP使魔、红、SP美西螈、SP雪狐、SP悦灵都强依赖资源条。魔力、湿润值、霜寒值和水晶能量决定它们能否连续作战。

### 控场与召唤型

SP雪狐、SP堕落悦灵、SP阿努比斯偏向改变战场：冰风暴吸附、恼鬼追击、死亡领域改造地形，都会迫使敌人改变站位。

### 刺杀与爆发型

SP野猫、契灵、金沙岚更偏向选定目标后完成爆发。它们的强度来自隐身先手、烙印推进或百分比结算，而不是无脑站桩。吸血蝙蝠则是典型的夜战近战猎手：靠血渴值越打越强，但白天与面对铁器时格外脆弱。食梦魔把“先累计伤害再处决”做成节奏型刺杀；朔望则用九命容错换舍身自爆的团灭级爆发。

### 团队辅助型

SP悦灵的定位最接近纯辅助：净化、治疗、图腾守护与远程增伤让它在多人环境中价值很高，但自身生命很低，需要队友保护输出窗口。寄生果蝠则以“种子」运营为核心：给友方挂增益果、给敌方挂削弱果，并用感染孢子弹提供持续的群体压制与团队治疗。

## 白名单说明

多数范围伤害、控制、治疗与召唤物索敌走 SSCA 白名单。可用 [`/ssc_addon my_whitelist`](../commands/commands.md) 管理自己的名单。

- **名单为空**时，默认友方包括玩家、同世界玩家的已驯服宠物，以及具有受识别主人标记的生物。
- **名单非空**时，友方包括名单里的玩家和生物，以及名单中玩家的宠物和受识别召唤物。只添加生物也会启用这套判定。
- 常规攻击性技能跳过受保护目标，接入友方判定的治疗和强化会作用于自己与符合条件的友方。个别法术有自己的规则，例如[爆裂魔法](../spells/catalog.md)会无差别结算。
