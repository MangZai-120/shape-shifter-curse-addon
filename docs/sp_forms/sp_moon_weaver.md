# 月织蛛 —— 月下织网者

**Moon Weaver**

> "别的猎手追逐猎物，
> 而你只是把网织在它必经的路上，然后等。"

月织蛛是三阶段蜘蛛的月髓十字环 SP 分支，在原版蜘蛛的网猎玩法上叠加了**蛛网控场、蛛丝摆荡与二段跳机动**。整体节奏是先用蛛网控场，再靠机动收割。

!!! warning "不可逆转"
    虽然属于 SP 形态，但与原版幻形者诅咒的 SP 形态不同，本附属的所有 SP 形态并**不能**使用抑制剂/强效抑制剂逆转。

## 附属新增能力与修改

### 1. 织网模式与手势

潜行时快速双击 主技能键，切换搭路与攻击模式。

模式跨形态保存。普通长按主键后松开，按当前模式发射搭路弹或攻击网弹；搭路模式下潜行长按，或不潜行双击后按住，可平铺脚下桥路。

长按判定约0.25秒，双击窗口约0.3秒。起手需要至少6点蛛丝法力，这6点只是启动门槛，不会一次性额外扣除。

### 2. 三档攻击织网

切到攻击模式，按住 主技能键 蓄力后松开。

默认在20／40／60 tick提示三个档位，最高档保持不再耗法。实际蓄力每tick消耗0.25，达到这三个时点分别累计5／10／15；松开后按实际档位冷却1／2／3秒。铺网核心半径依次3／5／6格，外围还有稀疏溅射。

弹着点8格内进行随距离、档位和已有缠身变化的概率裹茧；未中签者缠身5秒。直接命中另外确定性累加200／400／600 tick缠绕，满500转完整裹茧，故三档直击可确定裹茧。白名单受到保护；未佩戴纺锤。提前松开仍按第一档结算，实际耗法不固定等于5。

### 3. 平铺搭桥与搭路弹

搭路模式下潜行长按 主技能键 后松开；普通长按则发射搭路弹。

平铺按三个档位生成10／14／18格蛛丝桥，普通搭路弹可在命中表面建立蛛丝梯。附属搭桥和搭梯允许替换已有网膜，避免攻击模式留下的薄网阻断道路。

蓄力耗法和分档冷却与攻击模式相同。录像在真实缺口旁展示桥长，并单独展示墙面搭梯；桥块和薄层网膜是两种方块，桥本身不触发本页的蛛网亲和。

### 4. 挂墙摆荡与收放绳

瞄准方块按 副技能键 挂丝，再用空格收绳、空中潜行放绳，移动键调整摆荡。

最远32格。飞弹每飞行2格消耗1点法力，放绳同样每延长2格消耗1点；收绳与单纯维持不另扣法力。再次按副键主动断开，结束或射空后进入5秒冷却。

至少1点法力才能发射；不够时不会开始冷却。过远或被实体方块遮挡会断丝。空格用于收绳期间不触发二段跳；录像保留真实位移与绳长变化。

### 5. 牵引友敌与非玩家强化

用 副技能键 的飞弹命中生物。

命中额外消耗8点蛛丝法力，不足扣到零。固定16格绳长，不可放长；约12格开始软拉，超过16格加强牵引，近距离可自由活动。友方绿边、敌方蓝边只向施法者显示。

白名单也能连接，便于协作。对被你牵住的非玩家敌方生物，你造成伤害增加15%，其对你伤害减少40%；玩家和白名单不获这组额外修正。再次按副键可断开。

### 6. 蛛网亲和

站在或触碰原版蜘蛛网、附属网膜。

移速属性增加20%，每秒额外回复1点蛛丝法力，受到伤害减少20%。

普通地面、原版蜘蛛网与自织网膜并排对照。额外回复与原有自然回复共同出现；通用法术蓄力时暂停这笔额外回复。原版条件修正也参与最终移速结算，因此两种蛛网上的最终数值可能不同。临时桥块不触发本亲和。

### 7. 月毒侵蚀

靠近已经蜘网缠身或完整裹茧的敌人。

每3秒检查附近约8格的受困目标，施加4秒中毒I，持续受困时可刷新。白名单不受此被动影响。

录像把普通目标、缠身目标、裹茧目标和远处缠身目标并列。判定读取目标当前状态，不要求这次控制必须来自本人；范围按方块包围盒检查。

### 8. 茧化猎手与生物增伤

近战攻击完整裹茧的目标。

基础近战增伤15%；非玩家敌方生物另外增加25%伤害，与前者相乘，近战合计倍率1.4375。

同一把木剑分别攻击普通、裹茧及白名单裹茧目标。白名单不获得额外的非玩家25%。命中茧化目标回法是继承的原版能力，本页把它与附属增伤分开说明。

### 9. 蛛丝二段跳

离地后松开再按一次跳跃键。

一次滞空最多追加一次二段跳，落地后恢复次数；疾跑时还带前冲。

连续三次空格对照：首跳、二段跳、第三次不再追加。挂着摆荡蛛丝时空格改为收绳，不能同时二段跳。

### 10. 薄层网膜与接触免疫

让生物走上或接触网膜。

非免疫生物接触时水平速度按0.7处理，获得5秒蜘网缠身，并踩毁接触到的那块网。缠身还降低移速，联动挖掘疲劳和虚弱，牛奶不能清除。

白名单、蜘蛛实体、月织蛛和指定悦灵形态免疫接触效果；保护检查使用网主。网主离线或归属未知时，默认保护玩家和已驯服宠物。离开后效果按剩余时间结束。

### 11. 自然消散与水冲

等待技能网膜的真实自然计时，或让水接触它。

每块网膜独立在60～90秒间自然消失；水接触会提前冲毁，且不掉落物品。网膜也可燃。

录像保留完整自然等待，再单独展示水冲。清掉后重新铺设的网有独立到期时间，旧消散任务不会让新网提前消失；计时随存档保存。自然寿命镜头保持空场，没有加速世界时间。

### 12. 投射法术织网

用法术书发射投射物法术，起手时至少8点蛛丝法力。

整次施法只支付8点蛛丝法力；投射物命中地面上表面留下约3×3网膜。直接有效命中不铺地网，并有15%概率完整裹茧，非玩家生物15秒、玩家5秒。

同次施法对同一目标只抽一次。白名单受保护，穿刺直击后不再铺网，墙面命中不铺地网。丝量不足仍能普通施法，不扣额外蛛丝、不附加织网；录像包含一次概率成功示例，不表示必定触发。

### 13. 织月与月辉亲和

使用月辉系法术命中敌人。

月辉系伤害增加15%，有效命中额外回复2点原版蛛丝法力，受通用命中回资源间隔限制。

同一张1级月辉之矢分别由人形态和月织蛛施放。投射法术织网的8点起手成本仍独立存在，命中回2并不代表本次施法不耗蛛丝；白名单不计有效敌对命中。

## 原版继承特性

攀爬墙壁、蛛网内自由穿行不减速、夜视、毒素免疫、节肢生物组（蜘蛛友好、铁傀儡敌对）、摔落保护、自动进食、可食用线与蜘蛛液茧回复法力、额外手臂持辅助工具等原版蜘蛛第三阶段的全部本能。

## 弱点与限制

| 限制 | 说明 |
| --- | --- |
| 护甲限制 | 无法装备胸甲、腿甲与靴子 |
| 节肢弱点 | 作为节肢生物，燃烧时受到的伤害提升 |
| 地面迟缓 | 在地面行走时移动速度被削弱 |
| 食性限制 | 基本食性只剩蜘蛛液茧与线，其它食物难以下咽 |
