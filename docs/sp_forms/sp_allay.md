# SP 悦灵 —— 水晶之音

[查看水晶之音的实机教程](../tutorials/crystal-sound/index.html)

**Allay SP / Crystal Sound（水晶之音）**

> "悦灵的歌声不只会安抚伤口。\
> 当水晶共鸣被推到极限，它也能净化战场、托住将死的同伴，并把一次孤身作战变成短暂的祝福。"

SP 悦灵是以**群体净化、群体治疗、远程增益**为核心的辅助形态。它的输出并不依赖近战，而是通过能量条和蓄力技能为队伍提供恢复、解控、保命与远程伤害增幅。

## 附属新增能力与修改

### 1. 群体净化

按 主技能键，自动蓄力1.5秒。

先清除自身与20格内未受白名单保护目标已有的全部增益、减益，再对敌方NPC施加虚弱II、缓慢I 15秒；成功冷却20秒。

同时打断法术、群疗等主动蓄力，其他悦灵的净化蓄力除外。受到伤害进入4秒失败冷却；再次按键可取消。NPC后加减益保留，玩家持续净化规则不变。两位玩家分别记录实际效果。

### 2. 群体治疗

至少100能量时按 副技能键，蓄力3秒。

成功后消耗全部能量，治疗20格内符合增益白名单规则的目标，回复其最大生命的75%；冷却15秒。

附加抗性提升I 10秒，以及按最大生命50%折算的黄心，持续30秒。黄心按4生命一档取整：20生命玩家实际获得12点，10生命水晶之音获得4点；双视角突出真实血量。

### 3. 独行祝福与打断反馈

范围内没有其他可治疗玩家时完成群疗。

自身仍获得75%最大生命治疗与黄心，另有力量II、抗性提升II各20秒，投射物伤害增加30%持续20秒。

有其他符合规则的玩家，即使满血，也不触发独行祝福。群疗被伤害打断时只获得抗性提升I和速度I各10秒，失败冷却3秒；未完成的群疗不会扣光能量。

### 4. 图腾守护

手持不死图腾按 使用键 激活，再放回自己的背包。

20格内符合增益规则的友方或自身受到致命伤害时，消耗这个激活图腾代为免死。

每次激活间隔20秒，同时只能持有一个激活图腾；离开持有者背包便失活。镜头由手中没有图腾的受援玩家拍摄，展示真实免死、黄心、再生与防火。

### 5. 便携信标

手持信标按 使用键 开关；激活后保留在自己背包内。

给自己和20格内符合增益规则的单位急迫II，每3秒消耗1能量；开启时暂停能量自动回复。

低能量演示展示自然耗尽并关闭。信标离开自身背包也会关闭；已施加的急迫可保留到该次效果自然到期。视频包含受援方第一人称。

### 6. 治疗术（形态工具）

选择快捷栏第一格的治疗术，对准20格内友方按 使用键。

每次消耗12能量，治疗目标8点生命，冷却2.5秒；需无遮挡并符合增益白名单规则。

工具自动配发，不是饰品或书内自疗法术。两位玩家分别记录实际治疗、能量消耗与冷却内尝试；使用后能量恢复暂停3.5秒。

### 7. 专属唱片机（形态工具）

背包光标拿起唱片，对快捷栏第二格的唱片机右键充能；潜行键 加 使用键 开关，普通 使用键 切换模式。

每张唱片消耗后增加300充能，上限600；开启时每秒消耗1。20格内符合规则的单位获得移速加10%与急迫I，或每3秒回复1生命并持续获得抗性I与4点黄心。

默认开启加速模式，切换模式冷却1秒。镜头保留真实背包充能、音乐、属性、回血与关闭后的变化；它是形态工具，不是继承的普通唱片机回血或饰品效果。

### 8. 水晶能量

观察能量条，并对比净化完成前后的恢复。

能量上限200，符合恢复条件时每8刻回复3点。

净化、群疗完成及应急食品等会设置恢复暂停；本段净化完成后暂停3.5秒。便携信标开启或书内法术蓄力时也不会自动回复。

### 9. 应急食品

饱食度耗尽且至少有50能量时等待自动触发。

消耗50能量，恢复1点饱食度。

按每秒检查；触发后暂停能量恢复3.5秒。视频从0饱食、50能量开始，观察两条数值的实际变化。

### 10. 水晶护佑

与人形态分别承受同样8点基础伤害。

常规单次伤害上限为自身最大生命的25%。

本配置最大生命10，因此该次伤害最多2.5；对照人形实际掉血8。虚空与直接杀死类伤害不受这一上限保护。

### 11. 远程命中回复

用弓命中敌人，并对比连续命中与隔一段时间再命中。

远程命中每3.5秒可恢复最大能量的8%，并回复1点生命；200能量上限时回复16。

本段用真实箭矢命中；能量自然恢复每次3点，与命中回复16点分别观察。原版已有的远程基础加成和其他击中回复不作为新增效果重复介绍。

### 12. 生命感知

观察20格内不同血量比例生物的轮廓。

大于80%为绿色；大于40%且不超过80%为橙色；不超过40%为红色。

视频在墙后放置满血、60%与20%血量目标，并显示实际目标血量；颜色表示当前生命比例。

### 13. 高级武器近战惩罚

人形态与水晶之音用相同铁剑攻击同配置目标。

主手武器采掘等级大于1时，近战伤害乘0.5。

铁、钻石等符合条件武器受到这一惩罚；这不是所有空手攻击统一减半。饮食与装备限制仍保留，缩放食物不再额外豁免；创造飞行下的采掘减速与其他乘区分别计算。

### 14. 交易优惠

对村民按 使用键，打开实际交易界面。

交互时获得短暂的村庄英雄II，用于本次交易优惠。

用同配置村民对照人形态的报价，观察界面中的实际物品需求；不是让玩家长期持有村庄英雄效果。

### 15. 伤害治疗联动

用书内法术使敌人实际掉血，附近需有受伤友方玩家。

敌人实际扣血的25%，平均治疗自身16格内受伤的白名单玩家，包含自己；每名玩家每次至少0.25生命，且不超过生命上限。

满血玩家不占份额，宠物和召唤物不参与。实际产生治疗后，整次施法追加一次已付崩解的15%；自伤、友伤、吸收和过量伤害不计。双人视角与满血对照展示真实结果。

### 16. 召唤亲和

人形态与水晶之音使用相同二级召唤月灵。

召唤系效果等级加1，上限5级；本段二级召唤从1只变为2只。

比较实际生成数量。亲和后的效果等级与费用等级按各自规则结算，不把额外月灵当成饰品效果。

### 17. 月辉冷却亲和

用相同等级月华治愈，比较真实法术共享冷却。

月辉系法术冷却乘0.9。

本段基础12秒的月华治愈变为10.8秒；只治疗自己。与原生净化、群疗及图腾激活的冷却分别计算。

## 继承能力

原版飘浮飞行、缓降、紫水晶食物与共鸣、击中回血、唱片回血、粉雪适配及装备限制继续保留。实机教程只介绍附属新增或修改内容，Perk与饰品效果不在本轮演示范围。

## 弱点与限制

| 限制 | 说明 |
| --- | --- |
| 生命很低 | 最大生命值降低 **10 点**，被集火时需要依赖飞行和治疗窗口 |
| 蓄力怕打断 | 净化与治疗都需要蓄力，受伤会转入短冷却 |
| 治疗吃满能量 | 群体治疗必须满能量才能发动，不能随时抬血 |
| 食性限制 | 主要食物限制为紫水晶碎片，普通食物适配较差 |
| 护甲限制 | 无法正常使用腿甲与靴子 |

## 战斗定位

**空中支援 / 团队保命核心**

SP 悦灵最适合在队伍后排或空中观察战场。主技能净化负责打断关键技能和清状态，次要技能群体治疗负责抬血，图腾守护则给关键队友额外容错。单人时，群体治疗会转化为孤身祝福，让它短时间获得更高的自保和远程输出能力。
