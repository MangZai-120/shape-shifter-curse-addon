# 跳蛛 —— 墙壁与天空的猎手

**Salticidae**

> "地面只是起跳的地方。
> 真正的战场在墙上、在空中、在猎物头顶。"

跳蛛是三阶段蜘蛛的进化石 SP 分支，以**蓄力跳杀扑击 + 安全丝拉回**为核心机动输出循环，辅以毒液范围伤害。它的天地是墙壁与空中，是最"跳脱"的蜘蛛形态。

!!! warning "不可逆转"
    虽然属于 SP 形态，但与原版幻形者诅咒的 SP 形态不同，本附属的所有 SP 形态并**不能**使用抑制剂/强效抑制剂逆转。

## 主动技能

### 跳杀（主技能键触发）

* 长按主技能键蓄力，蓄力越久索敌距离越大：基础 **3 格**，蓄满 60 tick（**3 秒**）最远 **16 格**。
* 蓄力期间移动速度减半；所有可扑目标浮现红色描边、准星最接近者浮现绿色描边（仅自己可见）。
* 松开后沿抛物线扑向锁定目标（无锁定目标则按准星落点扑出）；距离越远起跳越高，空中会追踪移动目标的提前量拦截点；目标跑出脱锁容差（与跳跃距离成正比）则扑空。
* 命中造成 **8 点物理伤害 + 中毒 II 160 tick（8 秒）+ 定身 7 tick（0.35 秒）**。
* CD：扑中 **240 tick（12 秒）**、扑空 **160 tick（8 秒）**。

### 安全丝拉回

跳杀结束后 **160 tick（8 秒）**内再按主技能键，可沿安全丝快速拽回起跳锚点（**不受冷却限制**）；丝线最长 **48 格**，被实心方块遮挡或拉回受阻都会断丝。

### 毒液（次技能键触发）

* **基础形态**：对前方 **2×2×2 格**区域内所有生物造成 **4 点**魔法伤害并施加中毒 I 300 tick（15 秒）。
* **毒液冲刺**：若跳杀后有安全丝连着自己（跳杀后 8 秒内），则改为沿准星方向冲刺 **6 格**，途中撞到敌方生物造成 2 点魔法伤害并停下，随后以自身为圆心 **3 格**半径内所有生物受 **6 点**魔法伤害与中毒 II 300 tick（15 秒）。
* CD **200 tick（10 秒）**。

## 被动技能

### 弹跳本能

正常跳跃高度提升至 **1.65 倍**，空中可二段跳；从任何高度坠下都不受坠落伤害。

### 毒牙

左键近战命中生物时注入毒液，使其中毒 I 100 tick（5 秒）；装备[毒液腺体](../items/trinkets.md#毒液腺体)饰品后变为中毒 II 60 tick（3 秒）。白名单内个体免疫。

### 掠食者之力

左键近战造成的伤害提高 **2 点**。

### 其它继承特性

节肢本能（蜘蛛友好、铁傀儡敌对）、辅助前肢（额外手臂持辅助工具与盾牌、额外图腾槽位）、夜视与毒免疫、攀爬（蛛网内自由穿行不减速）。

## 弱点与限制

| 限制 | 说明 |
| --- | --- |
| 肉食本性 | 只能从肉类食物中获得饱食 |
| 护甲限制 | 无法装备胸甲、腿甲与靴子 |
| 节肢弱点 | 作为节肢生物燃烧时受到的伤害提升 |
| 地面迟缓 | 在地面行走时移动速度被削弱——真正的天地是墙壁与空中 |
