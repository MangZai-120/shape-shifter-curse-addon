# 跳蛛 —— 墙壁与天空的猎手

**Salticidae**

> "地面只是起跳的地方。
> 真正的战场在墙上、在空中、在猎物头顶。"

跳蛛是三阶段蜘蛛的进化石 SP 分支，以**蓄力跳杀扑击 + 安全丝拉回**为核心机动输出循环，辅以毒液范围伤害。它的天地是墙壁与空中，是最"跳脱"的蜘蛛形态。

!!! warning "不可逆转"
    虽然属于 SP 形态，但与原版幻形者诅咒的 SP 形态不同，本附属的所有 SP 形态并**不能**使用抑制剂/强效抑制剂逆转。

## 附属新增能力与修改

### 1. 蓄力跳杀与命中结算

按住 主技能键 蓄力，瞄准后松开扑出。

默认蓄力3秒到顶，索敌从3格增至16格，蓄力移速减半。命中基础8点物理伤害，加中毒II 8秒及定身0.35秒；非玩家敌方生物的本体伤害和这两项时长翻倍。扑中冷却12秒，扑空8秒。

跳蛛自身的额外2点近战类型伤害也会参与跳杀，因此默认无护甲目标实测玩家10点、敌方生物18点直接伤害。后续毒伤和自动诅咒另算；基础8点并非最终扣血值。

### 2. 红边候选、绿边锁定与脱锁

蓄力中转动准星，松手时选定最终目标。

可见候选显示红边，准星约12°锥内最接近中心的目标显示绿边，仅本人可见。白名单和被方块遮挡的目标不参与锁定。

飞行中会追踪目标的提前位置；目标偏离起跳锁定位置超过本次跳跃距离的40%时脱锁。没有合法目标也会沿准星方向扑出，能用于移动；实际停靠距离还受惯性和落地影响。

### 3. 安全丝拉回

贴近地面起跳，跳杀结束后再按 主技能键。

跳杀结束后保留完整8秒拉回窗口；按主键可沿丝回到起跳锚点，即使主技能仍在冷却中也能使用。每次安全丝只能拉回一次，拉回结束消耗锚点。

拉回沿真实路径移动并保留碰撞，会在锚点附近减速停下；不是瞬间传送。飞行时间不再提前吃掉落地后的8秒，撞断或已消耗的丝不会因跳杀结束而重新出现。

### 4. 安全丝距离与断裂条件

留意脚下锚点、倒计时和拉回路径。

安全丝最大有效距离48格，按玩家与地面锚点的三维直线距离计算。超过距离、有效期结束、实心遮挡过厚或拉回受阻时会失效。

只有贴近可站立表面起跳才建立地面锚点；高空无地起跳没有这条回程丝。镜头展示自然到期与高空对照。48格是安全丝上限，蓄满的16格索敌范围单独计算。

### 5. 基础毒液与友军保护

没有安全丝时朝目标按 副技能键。

前方3.5×3.5×3.5格区域造成4点基础魔法伤害并施加15秒中毒I；非玩家敌方生物伤害乘1.5，默认6点。冷却10秒。

白名单目标不受影响。玩家受击视角与范围外对照均单独展示；区域中心跟随瞄准方向，不应按旧说明的2格立方体判断范围。

### 6. 丝线强化毒液冲刺

跳杀后仍有有效安全丝时，按 副技能键。

消耗安全丝，沿释放时朝向冲刺6格。撞到敌人造成2点基础魔法伤害并停下，随后以自身为中心4.5格毒爆，造成6点基础魔法伤害与中毒II 15秒。敌方生物伤害均乘1.5。

碰撞与毒爆独立结算：无护甲玩家共8点，敌方生物共12点直接伤害，后续中毒另算。修复仅让毒爆绕过本次碰撞产生的无敌帧。白名单保护保留，冲刺结束后的惯性不计入技能6格路程。

### 7. 毒牙

对非白名单生物造成有效伤害。

毒牙可施加5秒中毒I，本段用普通左键近战展示。更强或更长的中毒仍按原版效果合并规则处理。

白名单不施加毒牙。当前触发配置按有效伤害命中判断，原生技能伤害也可能触发，随后会被技能自身更强的中毒覆盖；不是所有镜头里的中毒都来自同一项能力。未佩戴毒液腺体。

### 8. 掠食者之力

用相同武器比较人形态和跳蛛。

近战类型伤害额外加2点。无护甲目标、同一把木剑，普通人形态4点，跳蛛6点。

此修正按伤害类型判断，跳杀的玩家近战伤害源同样受益；武器、护甲与其他乘区仍可能改变最终扣血。

### 9. 跳跃增强、二段跳与落地免伤

正常起跳后，离地松开并再按跳跃键。

首跳初速度获得额外1.65倍修正，与继承的其他跳跃修正共同结算；一次滞空还能再跳一次，落地恢复次数。跳蛛把继承的摔落保护改为完全免疫摔落伤害。

三次空格只触发首跳与一次二段跳，并单独从高处落地验证免伤。1.65修正作用于起跳速度，不能直接当成最终跳跃高度的倍数；二段跳使用自己的跳跃初速度。

### 10. 固定基础生命上限

变为跳蛛并观察白天与夜晚。

基础生命上限16点，即8颗心。

录像在同一形态下切换昼夜对照。装备、其他属性或模组仍可能改变最终生命上限。

### 11. 跳杀自动诅咒与诅咒亲和

用跳杀对合法敌人造成实际伤害，并装备含诅咒法术的法术书。

优先施放当前选中且可用的非红色诅咒；否则随机选择另一个可用的书内诅咒。自动施放只付正常崩解成本的20%，采用正常冷却的10%，不消耗卷轴次数。跳蛛的诅咒持续时间另加10%。

相同1级恐惧低语对照：普通手动成本18、冷却20秒；自动触发成本3.6、冷却2秒。持续效果由120 tick变132 tick，手动和自动均保留亲和。自动瞄准不转动玩家镜头；跳杀伤害被拒绝时不触发。

### 12. 免费白色诅咒兜底

没有法术书，或书内没有可用的非红色诅咒时，跳杀命中。

改为免费随机施放一个1级白色诅咒，不增加崩解，不生成或消耗卷轴物品。

原有卷轴和共享冷却不会被兜底缩短；只放在背包、没有装入法术书的卷轴不参与书内优先选择。投射型兜底仍真实发射，之后能否命中取决于位置和飞行，并非直接强制给目标上状态。

### 13. 肉食补给与蛛丝资源取舍

持肉类食物按住 使用键 进食。

跳蛛改用肉食补给，不继承三阶段蜘蛛的线与液茧食性，也不使用其蛛丝法力资源。

录像在饥饿时先尝试线，再实际食用熟牛肉，观察物品消耗与饱食度恢复。原生跳杀、拉回和毒液按各自冷却使用，不扣月织蛛的织网法力。

## 原版继承特性

节肢本能（蜘蛛友好、铁傀儡敌对）、辅助前肢（额外手臂持辅助工具与盾牌、额外图腾槽位）、夜视与毒免疫、攀爬（蛛网内自由穿行不减速）。

## 弱点与限制

| 限制 | 说明 |
| --- | --- |
| 肉食本性 | 只能从肉类食物中获得饱食 |
| 护甲限制 | 无法装备胸甲、腿甲与靴子 |
| 节肢弱点 | 作为节肢生物燃烧时受到的伤害提升 |
| 地面迟缓 | 在地面行走时移动速度被削弱——真正的天地是墙壁与空中 |
