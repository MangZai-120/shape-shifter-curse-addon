# Installation Guide

## Prerequisites

Requirements for the **SSCA 8.0.0 stable release**:

* **Minecraft** 1.20.1 and **Java** 17 or newer
* **Fabric Loader** 0.14.21 or newer
* **Fabric API** 0.83.0 or newer for Minecraft 1.20.1
* **Shape Shifter Curse (SSC)** 1.10.0
* **GeckoLib** 4.8.4 or newer for Fabric 1.20.1

## Installation Steps

1. Make sure Fabric Loader and Fabric API are installed
2. Download and install **Shape Shifter Curse** and **GeckoLib**
3. Download the **Shape Shifter Curse Addon** `.jar` file
4. Drop the `.jar` into your game's `mods` folder
5. Launch the game

!!! warning "Note"
    Download the built `.jar` for your Minecraft version.

## Version Recommendation

SSC 1.10.0 changed the form system and pairs with SSCA 8.0.0. For SSC 1.9.2 and older modpacks, match the dependency listed on the download. Older 1.21.1 test builds are separate downloads. [Download SSCA 8.0.0](https://modrinth.com/mod/shape-shifter-curse-addon/version/KWtJteVj)

## Compatibility

Install SSCA and the corresponding dependencies on both the client and the server. Use an accessory backend that matches your environment to equip accessories and spellbooks.

## Version Numbering

Version numbers follow `MAJOR.MINOR.PATCH`:

| Suffix | Meaning |
| --- | --- |
| no suffix | Stable release |
| `+hotfix.X` | Hotfix release |
| `-beta.X` | Public beta |
| `-dev.X` | Development build |
