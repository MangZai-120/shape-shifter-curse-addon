# 安装指南

## 前置要求

以下为 **SSCA 8.0.0 正式版**的前置要求：

* **Minecraft** 1.20.1，**Java** 17 或更高
* **Fabric Loader** 0.14.21 或更高
* **Fabric API** 0.83.0 或更高，选用 1.20.1 对应文件
* **幻形者诅咒（SSC）** 1.10.0
* **GeckoLib** 4.8.4 或更高，选用 Fabric 1.20.1 对应文件

## 安装步骤

1. 确保已安装 Fabric Loader 和 Fabric API
2. 下载并安装 **幻形者诅咒** 和 **GeckoLib**
3. 下载 **幻形者诅咒扩展包** 的 `.jar` 文件
4. 将 `.jar` 文件放入游戏的 `mods` 文件夹
5. 启动游戏即可

!!! warning "注意"
    下载对应 Minecraft 版本的 `.jar` 成品文件。

## 版本建议

SSC 1.10.0 更新了形态系统，配套使用 SSCA 8.0.0。仍在用 SSC 1.9.2 或旧整合包时，按对应下载文件标注的依赖配套。1.21.1 的旧测试文件是独立版本，安装时请核对游戏版本。[8.0.0 正式版下载](https://modrinth.com/mod/shape-shifter-curse-addon/version/KWtJteVj)

## 兼容性

联机时，客户端与服务端都需安装 SSCA 和对应前置。佩戴饰品及魔法书时，使用与运行环境匹配的饰品后端。

## 版本号命名规则

本模组的版本号遵循 `大版本.小版本.修订版` 的格式：

| 后缀 | 含义 |
| --- | --- |
| 无后缀 | 正式版 |
| `+hotfix.X` | 紧急修复版 |
| `-beta.X` | 公开测试版 |
| `-dev.X` | 开发版 |
