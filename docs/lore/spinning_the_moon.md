# 纺月

*作者：佚名*

---

很久很久以前，有一个被月亮偏爱得过分的山谷，那里的草是银白色的，草叶上挂着的露珠里，每一颗都住着一小片月亮。赶路的旅人叫它"银线谷"——可附近的老人只在一种时候提起这个名字：望夜，月亮最圆最亮的那一夜，山风忽然安静下来的那一瞬。

那一年的望夜，一支商队为了赶在冬天封山前把货送到山那头，决定连夜穿过银线谷。领队的老商人出发前在观月司的祭坛前站了很久，最后还是把一枚铜币投进了功德箱。看门的老祭司掀了掀眼皮，说了一句让所有人莫名其妙的话：

"月亮只照路，不照那些不赶路的人。"

他们没听懂，还是进了谷。

刚进谷口，月亮就升起来了。

那夜的月亮大得不像话。它低低地悬在谷口正上方，像一只银色的眼睛，俯瞰着这支小小的商队。月光落下来，把整座山谷铺成一层银毯，连马蹄踏过的青苔都泛着冷光。老商人压低了声音，一遍遍地叮嘱："都低着头，跟着领队就行，别看月亮。望夜的月亮，会吃人。"

可队伍里总有不信邪的。押尾的那个年轻伙计嗤笑一声，偏要扬起脸，对着那轮大得诡异的月亮看了个够。

他看了很久。久到前面的骡铃声都开始消散，他才回过神来。

然后他看见，自己肩上垂着一根银线。细细的，亮亮的，和蛛丝一样，在月光里轻轻晃动，像谁刚从月亮上抽出来的一缕。他伸手去拈——那根线冰凉，凉到指尖发麻，仿佛月光被谁拧成了一股实心的绳。

他没有喊。也许是喊不出，也许是不敢喊。他就那样站着，看着自己从指尖开始，一点一点被包裹起来，形成了一个茧。那个茧很快开始消散，直到他成为了一缕一缕的银丝，向着月亮的方向，轻轻地、缓缓地，飘。

等队伍里发现少了人、举着火把回来找的时候，山谷里只剩下一片安安静静的银草，和草尖上挂着的一张小小的蜘蛛网。网上没有露珠，只有月光。网心，住着一点更亮的光。

第二个消失的是赶骡子的驼夫。他一路低着头，数着骡蹄，数到第三百二十七下的时候，月光忽然晃了晃。

他手里那根缰绳，不知什么时候变成了一根银丝。软软的，长长的，直直地伸向黑暗的深处。他顺着那根丝往回拽，拽了两下——那头传来一阵轻轻的回力，像有人在另一头，安详地收线，收得很慢，很稳，像在缝一件旧衣裳。他撒手，转身就跑。可脚下的银草忽然活过来似的，一根根缠住他的靴筒；头顶垂下一根更亮的丝，轻轻绕住他的手腕，像母亲牵孩子的手，引着他一步步走回谷底月光最深的地方。

后来的人路过谷底，会在石壁上看见一片发着微光的薄薄的东西——那是一片网，网上缀满细碎的、亮晶晶的珠子。当地人从不伸手碰它，只说那不是露珠，是月光被织进去时，留下的线脚。

商队里最胖的那一位是这批货物的老板。他这一趟押的是山上最好的雪蚕丝，织成雪蚕布后，每一匹就能换半扇城楼。他一路上都在算账，算自己这一趟能赚多少钱，算得眼珠子直发亮。

可他走着走着，忽然觉得箱子越来越轻。他停下来，掀开箱盖，愣住了——

箱子里的雪蚕丝全没了，满满一箱，全都消失了，只有一箱透着月光般寒冷、轻盈的丝线。他伸手抓起那捆丝线的头，不停的向后抽。

他越抽越慌，越抽越快。那根丝没有尽头，被抽出的银丝就这么摊在地上，像一匹被拆掉的锦缎。他发疯地抽完最后一根，喘着粗气，低头去看那空荡荡的箱底——

箱底木板上，不知什么时候，被银色的丝线绣了一行歪歪扭扭的小字：

"月亮想要的，可不止你箱子里的丝。"

他猛地抬起头。谷里的月光下，队伍里剩下的人安安静静地站着，站成笔直的一排，低着头，一动不动。每个人的肩头，都垂着一根银线，一直延伸到月光照不到的黑暗里。山风在谷口打着旋，像一部古老的、看不见的纺车，吱呀，吱呀，吱呀。

远处，谷底最浓最亮的那片月光里，有一个比月亮更古老的身影，安安静静地坐着。

它纺的不是布。它纺的是月光。

它把月光纺成丝，把丝织成网，把网铺满整座山谷。网上挂满了人。那些人安安静静地缀在网上，像一截一截的月光，一动不动。而它还在一下一下地织，耐心得像永远都有明天。

他抱着箱子，头也不回地冲出了谷口，瘫倒在月光照不到的大石后面，拼命地喘气。他不敢回头，更不敢抬头看天。他已经不记得自己的名字了——不，他记得，只是那名字在心里滑得飞快，像一条光滑的鱼，怎么也抓不住。

天上有两个月亮。
