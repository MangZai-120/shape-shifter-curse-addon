# 法术异常与元素反应

法术的有效命中可在目标身上积累元素异常。每个元素独立计量，上限为 500。施法者自己的负荷见[崩解度](collapse.md)。

- 未满的元素条共享 20 秒保留时间，新的有效累积会刷新它。达到 500 时触发该系异常，并显示满条 5 秒。
- 同系在满条期间再次命中不会重新触发。另一系首次满条时，仍存在的满条一起刷新到 5 秒。
- 两系在 5 秒联动窗口内先后触发时，组合反应代替第二系的基础异常。参与反应的两次触发会消耗联动资格。满条时间和状态持续时间分别计时。

## 单系异常

| 元素 | 默认效果 |
| --- | --- |
| 烈焰 | 立即造成 8 点火焰反应伤害。 |
| 寒冰 | [冰封](https://www.mcmod.cn/item/1038982.html) 5 秒。后续有效伤害可破冰，留下 3 秒冰裂缓速。 |
| 月辉 | 月蚀 I，6 秒内治疗量降低 50%。 |
| 诅咒 | 衰咒 I，6 秒内造成的伤害降低 20%。 |
| 召唤 | 灵印 I，8 秒内受到的召唤伤害增加 25%。 |
| 虚无 | 虚蚀 I，6 秒内受到的法术伤害增加 15%。 |
| 空间 | 束界，5 秒内减速 30%，并限制空间跳跃、空间归途与口袋空间。 |

## 双系反应

| 组合 | 默认效果 |
| --- | --- |
| 烈焰＋寒冰 | 半径 5 格内造成 8 点魔法反应伤害。幸存目标受到烈霜，减速 50%，持续 5 秒。 |
| 烈焰＋月辉 | 月蚀 II，持续 6 秒。 |
| 烈焰＋诅咒 | 半径 3 格内施加衰咒 I，持续 5 秒。 |
| 烈焰＋召唤 | 炎灵持续 6 秒，接下来最多 3 次有效召唤命中各附加 2 点火焰反应伤害。 |
| 烈焰＋虚无 | 立即造成 4 点魔法反应伤害。 |
| 烈焰＋空间 | 生成半径 3 格的炎域，持续 5 秒，每秒造成 1 点火焰反应伤害。 |
| 寒冰＋月辉 | 月蚀延长至至少 9 秒。 |
| 寒冰＋诅咒 | 衰咒 III，6 秒内造成的伤害降低 35%。 |
| 寒冰＋召唤 | 霜猎持续 6 秒，下一次有效召唤命中附加 6 点魔法反应伤害。 |
| 寒冰＋虚无 | 立即造成 6 点魔法反应伤害。 |
| 寒冰＋空间 | 冰锁，5 秒内无法疾跑。 |
| 月辉＋诅咒 | 月蚀与衰咒各延长至至少 9 秒。 |
| 月辉＋召唤 | 灵月持续 6 秒。有效召唤命中为召唤者最多恢复 1 点生命，总实际恢复上限 4 点。 |
| 月辉＋虚无 | 虚蚀 II，持续 6 秒。 |
| 月辉＋空间 | 半径 3 格内施加月蚀 I，持续 5 秒。 |
| 诅咒＋召唤 | 厄灵，6 秒内对召唤物造成的伤害降低 50%。 |
| 诅咒＋虚无 | 衰咒 II 与虚蚀 II，各持续 6 秒。 |
| 诅咒＋空间 | 半径 3 格内施加衰咒 I 和冰锁，各持续 5 秒。 |
| 召唤＋虚无 | 灵印 II，持续 8 秒。 |
| 召唤＋空间 | 半径 3 格内施加灵印 I，持续 8 秒。 |
| 虚无＋空间 | 半径 3 格内施加虚蚀 I，持续 5 秒。 |

冰裂缓速、烈霜、束界共用的减速取最强值。同时满足灵印与虚蚀的同一次伤害取较高易伤。衰咒和厄灵同时影响对召唤物的伤害时，也取更强的削弱。炎灵、霜猎和灵月的命中次数或治疗额度由实际反应生成。
