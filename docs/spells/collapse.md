# 崩解度机制

崩解度是施法者自身承担的负荷。手持卷轴和通过月尘魔法书施法共用同一个崩解值。形态原生技能仍使用各自的资源。

## 安全阈值与施法风险

- **安全阈值**由形态基础承载、玩家施法经验和已装备书中的增能法阵共同决定。默认每累计 600 点玩家施法经验提高 50 点阈值。增能法阵每级提高 10 点，只计最高等级。
- **当前崩解度**随施法增加。读条法术会分段结算，打断后保留已支付的部分。成功使用同一法术积累熟练度，可减少该法术后续带来的崩解度。
- 当前值高于安全阈值时，施法可能失败、发生偏移或引发反噬。随机失败在允许打断的准备阶段触发。已经进入受保护释放阶段的施法保留其保护。
- HUD 白线表示安全阈值，条形到两倍阈值时填满。超过显示范围后，数字仍显示实际崩解度，并出现溢出提示。

## 超载惩罚

设当前崩解度为 C、安全阈值为 N。以下为默认规则，区间右端点属于该行。每 2 点生命为 1 颗心。

| 当前崩解度 | 移速降低 | 生命扣除 | 屏幕效果 |
| --- | ---: | --- | --- |
| C ≤ N | 0% | 无 | 无 |
| N < C ≤ 1.2N | 15% | 无 | 无 |
| 1.2N < C ≤ 1.4N | 30% | 无 | 无 |
| 1.4N < C ≤ 1.6N | 40% | 每秒 1 点 | 无 |
| 1.6N < C ≤ 1.8N | 60% | 每 0.5 秒 1 点 | 反胃 |
| C > 1.8N | 80% | 每 0.5 秒 2 点 | 反胃、失明和凋零视觉表现 |

崩解惩罚直接扣生命值，绕过护甲和伤害吸收。致死时可触发不死图腾或可用的朔望九命。创造模式免于持续扣血。

## 恢复

默认在停止施法且距最后一次崩解增长约 6 秒后开始恢复。未装备书时每秒恢复 5 点。装备书时，默认速度为 `5 × (书等级 + 2) ÷ 3 × (1 + 0.20 × 回息法阵等级总和)` 点/秒。切换形态或死亡重生会清空当前崩解度和恢复等待时间。

[月尘药水](../items/tools.md#moon-dust-potions)可直接降低已累积的崩解度。[MC 百科机制图与示例](https://www.mcmod.cn/item/1036560.html)
