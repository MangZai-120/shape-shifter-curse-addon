# 进化用品

进化用品是 SP 形态进化的关键道具。不同的形态需要不同的进化用品来触发进化。

---

## 月髓十字环

**Moon Essence Cross**

| 属性 | 值 |
|------|-----|
| 物品命令 | `/give @p ssc_addon:sp_upgrade_thing 1` |
| 最大堆叠 | 1个/组 |
| 分类 | 进化用品 |

### 描述

> "一枚凝结着月华与诅咒的金色十字。当紫色的月光笼罩大地，唯有挣脱血肉束缚的幻形者，方能在月相交汇的刹那触碰其真正的力量——或是蜕变为超越凡躯的形态，或是被月髓中奔涌的狂躁能量撕裂魂魄，炸裂成一场璀璨而致命的星尘雨。此物非钥非刃，它是与月华签订的双生契约：一半是升华的辉光，一半是湮灭的冰裂。——谨记，唯有月光为尊。"

### 合成配方

使用工作台合成：

| 材料 | 数量 |
|------|------|
| 金锭 | 4 |
| 绿宝石 | 1 |
| 红石粉 | 1 |
| 塑形核心 | 1 |
| 月尘纯晶 | 1 |
| 下界合金锭 | 1 |

!!! note "布局"
    金锭放在四角，中心是塑形核心。上、左、右、下分别放绿宝石、红石粉、月尘纯晶、下界合金锭。

### 使用条件与效果

长按右键约 1.6 秒。以下是生存模式下的常规结算。形态与路线对照见[形态概述](../sp_forms/overview.md)。

| 条件组合 | 效果 |
|----------|------|
| 诅咒之月夜晚，当前形态满足进化条件 | 向相应形态进化，消耗十字环 |
| 诅咒之月夜晚，已是受十字环重复使用惩罚的形态 | 触发破坏方块的爆炸。非和平难度下使用者还会承受 100000 点基础伤害 |
| 诅咒之月夜晚，当前形态不支持该路线 | 消耗十字环，受到 10 点基础侵蚀伤害及 20 秒缓慢 II、虚弱 II、挖掘疲劳 II |
| 其余时间 | 消耗十字环，常规进化不发生 |

进化使魔或进化美西螈在分支条件未满足时，会在扣除物品前被拦截。阿澪也可以用它直接[还原为荧光幼灵](../sp_forms/sp_fluorescent.md#aling)，不消耗十字环。

### 适用形态

- SP使魔（灵界之主）
- SP美西螈（深渊霸主）
- SP堕落悦灵（堕落之灵）
- SP阿努比斯（冥裁者）
- 吸血蝙蝠（嗜血者）
- 风灵、寒棘狐、月织蛛、食梦魔

## 进化石

**Evolution Stone**

| 属性 | 值 |
|------|-----|
| 物品命令 | `/give @p ssc_addon:evolution_stone 1` |
| 最大堆叠 | 1个/组 |
| 分类 | 进化用品 |

### 描述

> "这是一颗仿佛自最深梦境中打捞上来的宝石，其形态宛若一颗永恒的、凝望深渊的猫瞳。在静谧的暗夜中，你能窥见其内部瑰丽的宇宙：幽匿的青色脉络如命运的神经般蔓延，猎杀的猩红余烬在核心缓缓跳动，夜视的流萤微光与终幕的虚空星云在其间交织盘旋，而一切光芒最终都被暗影的无垠基石温柔吞噬，归于一片沉静的漆黑。"

> "当紫水晶的共鸣、回声碎片的低语、钻石的恒久、幻鳞核心的蜕变之力与月尘纯晶的月华在下界合金的炽烈基石中交融，它们便凝结成一颗拥有脉搏与呼吸的活性核心。它宛如一颗沉睡的心脏，在掌心低语着关于潜行、猎杀、坚韧、视野与虚空的古老歌谣——只为等待一位能与之共鸣的宿主，完成那场命中注定的觉醒。"

### 合成配方

使用工作台**无序合成**：

| 材料 | 数量 |
|------|------|
| 紫水晶碎片 | 2 |
| 回声碎片 | 2 |
| 钻石 | 2 |
| 塑形核心 | 1 |
| 月尘纯晶 | 1 |
| 下界合金锭 | 1 |

!!! info "无序合成"
    上述材料在工作台中任意摆放即可合成，无需固定位置。产出 1 个进化石。

!!! note "自然获取"
    进化石也会以极低概率（约 **1.5%**）自然生成于以下结构的宝箱中：沉船补给舱、沉船宝藏舱、远古城市、堡垒遗迹（宝藏/其它/桥/疣猪兽棚）、末地船与末地城宝藏。

### 使用方式

长按右键使用（需持续约 1.6 秒）。用于**非诅咒之月形态**的进化，**不要求**夜晚或诅咒之月存在——只需玩家处于对应基础形态即可。

- 若当前形态**无对应进化目标**：提示"进化石未响应你的请求"，不消耗进化石。
- 若处于**进化使魔 / 进化美西螈**形态但进化分支尚未完全解锁：提示"进化分支尚未完全解锁"，不消耗进化石。
- 若处于**对应基础形态**：提示成功、消耗 1 个进化石，伴随黑屏淡入淡出的变身动画与短暂定身。

!!! tip "与月髓十字环的区别"
    进化石与月髓十字环走**完全不同**的两条进化路径：月髓十字环需要「天黑 + 诅咒之月 + 对应形态」，而进化石只需「对应形态」。某些原版最终形态（如使魔三阶段、美西螈三阶段）同时挂在两条路径上，但产出**不同**的 SP 形态——例如使魔三阶段用月髓十字环进化为灵界之主，用进化石则进化为契灵。

### 适用形态

每次进化消耗 **1 个**进化石：

| 基础形态 | 进化目标 |
|----------|----------|
| 野猫（原版 SP） | 月光魅影 |
| 雪狐（三阶段） | 寒霜之灵 |
| 悦灵（原版 SP） | 水晶之音 |
| 胡狼（三阶段） | 金沙岚 |
| 使魔（三阶段） | 契灵（禁忌兵器） |
| 进化使魔（需解锁全部分支） | 契灵（禁忌兵器） |
| 蝙蝠（三阶段） | 寄生果蝠（移动果园） |
| 美西螈永久形态（三阶段） | 荧光幼灵 |
| 进化美西螈（需解锁全部分支） | 荧光幼灵 |
| 豹猫（永久形态） | 朔望 |
| 蜘蛛（三阶段） | 跳蛛 |

## 灵能宝珠

**Psionic Orb**

凝聚灵能的宝珠，蕴含形态转换之力，仅进化形态可用。

| 属性 | 值 |
|------|-----|
| 物品命令 | `/give @p ssc_addon:psionic_orb 1` |
| 最大堆叠 | 1个/组 |
| 分类 | 进化用品 |

### 使用方式

长按右键，在进化形态之间**转职**。

* 需要**至少 3 点**加点点数才能使用。
* 转职会**倒退 3 个里程碑档**作为代价。

合成时，四角放紫水晶碎片，四边放月尘纯晶，中心放末影珍珠。

## 定形锚与解锚符

- [定形锚](https://www.mcmod.cn/item/1040540.html)右键成功使用时消耗 1 个，固定当前形态和本能值。死亡重生、重新登录后仍保留固定。适用于有可变本能、未被 SSC 自身锁定的形态。
- [解锚符](https://www.mcmod.cn/item/1040541.html)右键成功使用时消耗 1 个，解除定形锚产生的固定。SSC 形态自身的锁定仍由 SSC 管理。
- 主世界处于诅咒之月期间或玩家正在变形时，不能施加或解除固定。
